# normGM v1.0.0

This is the initial reproducibility release accompanying the manuscript
*Multiscale Schmidt-Spectrum Bounds for High-Dimensional Entanglement:
Geometric Measures and Schmidt-Number Witnesses*.

The release contains:

- scripts for the numerical examples and sensitivity calculations;
- machine-readable JSON, CSV, and plot-data outputs;
- statistical interfaces and empty raw-count templates;
- run instructions, environment records, and SHA-256 checksums.

The package does not contain setting-resolved experimental observations. The
published-summary calculations use values reported in cited articles and a
deterministic figure-digitization screening input. See `README.md` and
`REPRODUCIBILITY_RECORD.md` for scope and limitations.
